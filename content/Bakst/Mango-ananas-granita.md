# Mango-ananas-granita

## Ingredienser

- 300 ml frosen mango-stykker
- 300 ml fersk ananas-stykker, konservert eller frosen kan brukes
- 500 ml papaya-nektar, (applesirup kan byttest)
- 125 ml honning, (stjernefulle, appelsinblomsthonning eller annen lett sitrus-honning)
- 2 store limer, bare saft

## Fremgangsmåte

1. Bland alle ingredienser i blender eller matprosessor.
2. Frys etter iskrem-maskin-produsentens instrukser.
3. Granitaen er glatteste når servert umiddelbar.
4. Pak inn i lufttett beholder og frys for lagring.
5. Iskrystallene blir mer markert ettersom det blir liggende i fryseren, og det er helt tiltalende.
6. Skje det eller bryt inn stykker for servering. Serv med fersk ananas- eller papaya-skivor.

## Info

- **Porsjoner**: 4 Utbytte: 700 ml
- **Type**: Dessert
